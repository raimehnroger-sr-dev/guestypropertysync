Incremental optimisation of the Quay Holidays Guesty Property Sync v3.4.0 architecture, following the July 2026 optimisation plan while preserving the existing Quay Elementor and booking integration.

== Description ==

Version 3.5.0 implements the plan's nine targeted optimisation items: lazy frontend API loading, calendar/quote caching, HMAC webhook authentication, locally synced pricing/filter metadata, advanced search, booking totals/coupons, checkout policy/consent, booking/revenue dashboard stats and an activity log.

It is a replacement for the current Quay Guesty plugin and should not be activated beside it.
